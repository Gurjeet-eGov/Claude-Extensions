Install the helper (one time)

In Terminal, run the installer from the folder you downloaded:

cd <bug-reporter folder>/host && ./install.sh

Then click Re-check. This extension's ID is .

The helper is ready. Next: add your project boards in the Projects tab.

Recording

Defaults keep a 60-second clip under 10 MB, GitHub's video limit on free plans.

Raise the cap to 100 MB only if your org is on a paid GitHub plan.

Claude

Claude only writes the title and the Description / Actual / Expected text, in one short call with no tools and no thinking. Detailed drafts read a condensed copy of the attached calls' request and response; the full cURL and response are always added to the issue by the extension. Dropdowns, the duplicate search and filing never use Claude.

Test Run

Test Run is the console for your manual test cases (test-run-console in this repo). When it is reachable, the Report Issue form shows Also add this to Test Run, with the test suite and, optionally, the test case. Once the issue is filed, a picked test case is marked failed with the issue linked to it; with no test case, the bug is added as a finding, ready to be written up as a test case.
